# 🔐 Password Generator App

A simple and secure password generator that creates strong random passwords up to **32 characters** long.

## Features

* Generate secure random passwords
* Password length up to 32 characters
* Fast and lightweight
* Easy to use
* Helps improve account security

## How It Works

The application generates a random password using a combination of:

* Uppercase letters (A-Z)
* Lowercase letters (a-z)
* Numbers (0-9)
* Special characters (!@#$%^&*)

This ensures that each password is strong and difficult to guess.

## Installation

Clone the repository:

```bash
git clone https://github.com/M-Taimoor-Mansha/password-generator-app.git
```

Move to the project directory:

```bash
cd password-generator-app
```

Run the application:

```bash
python main.py
```
